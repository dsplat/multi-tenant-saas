# 系统入门指南

## 系统是什么

这是一套多租户 SaaS 平台：平台方开设租户，租户运营自己的业务与用户。所有数据按租户隔离。

## 三个入口

| 入口 | 路径 | 谁使用 |
|---|---|---|
| 平台运营后台（admin） | `/admin` | 平台运营人员（Operator，scope=platform），管理租户、套餐、计费、平台配置 |
| 租户运营后台（console） | `/console` | 租户运营人员（Operator，scope=tenant），管理本租户的业务、用户、数字员工 |
| 用户前台（app） | `/app` | 被服务的用户（User），可开放注册 |

## 两种身份

系统只有两种可登录身份：

- **Operator（运营人员）**：登录后台运营的人。平台运营进 admin，租户运营进 console。一个 Operator 可以关联多个租户。
- **User（用户）**：被服务的用户，访问前台 /app，通过租户关联归属。

## 两种角色

后台角色只有两档：

- **tenant_admin（管理员）**：租户内的完整管理权限。
- **member（成员）**：普通成员权限。

## 常见问题

**Q：怎么切换租户？**
Operator 关联多个租户时，登录后进入卡片式租户选择页（Vue3 + Element Plus），点击目标租户卡片即可进入 console 后台。也可在顶部租户切换器切换当前操作的租户。

**Q：忘记密码怎么办？**
登录页点击"忘记密码"，通过绑定邮箱重置。

**Q：如何邀请同事进入后台？**
在 console 的成员管理中发送邀请，被邀请人接受后成为本租户的运营人员。
