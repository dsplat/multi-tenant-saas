# AI 推理引擎使用手册

## 模块简介  
AI 推理引擎是支持企业级智能应用的核心能力平台，提供 Agent（数字员工）、工具注册、记忆系统、AI 网关及多模态生成服务。该模块实现从对话交互到复杂任务执行的全链路自动化，帮助运营人员构建可配置、可监控、可扩展的智能工作流。  

主要解决以下业务问题：  
- 实现基于角色的智能助手（Agent）快速创建与管理；  
- 支持跨系统工具调用与知识库联动，提升自动化效率；  
- 提供对话记录、用量统计与成本监控，保障资源合理使用；  
- 通过统一网关接入多种 AI 能力（文本、图像、视频），降低集成复杂度。

## 核心功能

### Agent 管理  
用于创建、配置和维护数字员工（Agent）。每个 Agent 可设定角色、系统提示词、绑定工具与知识库，并控制其启用状态。  

- **创建 Agent**：根据模板或自定义配置新建一个数字员工。  
- **克隆模板**：从预置模板快速复制生成新 Agent，适用于标准化场景。  
- **启用/禁用**：动态开关 Agent 的可用性，不影响历史数据。  
- **模型配置**：为 Agent 设置专属推理模型参数，支持按需调整。  
- **工具与知识库管理**：为 Agent 绑定外部工具或关联内部知识库，增强任务处理能力。  

> 注：Agent 一旦创建，其租户 ID 与唯一标识不可更改。

### 对话与会话管理  
支持用户与 Agent 进行多轮对话，具备完整的会话生命周期管理能力。  

- **启动对话**：向指定 Agent 发起新对话，获取初始响应。  
- **发送消息**：在已有会话中继续交流，支持流式传输（SSE）。  
- **查看对话列表**：获取当前租户下所有 Agent 的历史对话记录。  
- **查看单个会话**：查阅某次对话的完整上下文与消息内容。  
- **删除会话**：清除特定对话记录，释放存储资源。  

> 所有对话均保留上下文信息，支持记忆压缩以优化性能。

### 工具与能力管理  
集中管理可被 Agent 调用的外部工具，包括系统内置与租户自定义工具。  

- **查看工具列表**：浏览当前租户及全局可用的工具。  
- **新增工具**：注册新的工具，定义其名称、类别、参数结构与执行逻辑。  
- **更新/删除工具**：修改工具配置或移除不再使用的工具。  
- **工具调用日志**：追踪每次工具执行的输入、输出、耗时与结果状态。  

> 工具可通过 Function Calling 方式被 Agent 自动调用。

### 用量与成本监控  
实时监控租户在 AI 服务上的资源消耗情况，支持预算控制与成本分析。  

- **Token 使用量统计**：查看文本类请求的输入与输出 Token 数量。  
- **成本估算**：基于模型定价与实际用量计算费用支出。  
- **工具调用日志**：记录每一次工具调用的详细行为。  
- **用量汇总**：按类别、模型、时间周期聚合使用数据。  

> 支持设置月度预算上限与超额处理策略，防止超支。

### 多模态生成服务  
集成图像、视频等非文本类 AI 生成能力，支持多样化内容创作需求。  

- **文本生成图像**：将自然语言描述转化为高质量图片。  
- **图生图 / 图像编辑**：基于现有图像进行风格迁移、局部修改或增强。  
- **文本生成视频**：根据文案生成短视频内容。  
- **图生视频 / 视频编辑**：将图片转换为视频，或对已有视频进行风格化处理。  

> 所有生成任务均以异步方式提交，可通过任务状态接口查询进度。

## 常见操作流程

### 创建并启用一个数字员工（Agent）

1. 进入 Agent 管理界面，点击“新建 Agent”；  
2. 选择一个预置模板（如客服助手、内容创作者），或从零开始配置；  
3. 填写 Agent 名称、角色描述、系统提示词；  
4. 在“工具”选项卡中，选择需要绑定的工具（如数据库查询、邮件发送）；  
5. 在“知识库”选项卡中，关联相关文档库；  
6. 保存后，进入“启用”状态，使该 Agent 可对外提供服务。

### 启动一次智能对话

1. 选择已启用的 Agent；  
2. 点击“开始对话”，系统生成新会话；  
3. 输入用户问题，系统自动调用 Agent 执行推理；  
4. 查看返回结果，若需继续交流，可在同一会话中追加消息；  
5. 对话结束后，可选择保留或删除该会话。

### 监控 AI 使用情况

1. 进入“监控”模块，选择目标 Agent；  
2. 查看“Token 使用量”图表，了解近期文本处理负载；  
3. 查阅“成本”数据，确认是否接近月度预算阈值；  
4. 审查“工具调用日志”，排查异常或失败调用；  
5. 若发现用量激增，可结合“配额”与“预算”策略进行干预。

### 注册并使用自定义工具

1. 进入“工具管理”页面，点击“新增工具”；  
2. 填写工具名称、分类、参数 Schema（JSON 格式）；  
3. 指定处理类（handler_class），确保其符合框架规范；  
4. 保存后，该工具将出现在工具列表中；  
5. 在 Agent 配置中将其绑定，即可在对话中被自动调用。

## 相关配置说明

### 租户级 AI 配置  
通过 `AiConfigService` 管理租户范围内的 AI 能力开关与策略：

- 开启/关闭文本、图像、视频类 AI 功能；  
- 设置允许使用的模型列表（可覆盖系统默认）；  
- 配置自定义 API Key（优先于系统默认）；  
- 设定月度预算上限（0 表示不限制）；  
- 定义超额时的行为策略（如阻断请求、仅告警）。  

> 配置变更立即生效，影响所有后续请求。

### 提示词模板管理  
支持创建可复用的提示词模板，用于标准化对话引导：

- 创建模板时可定义变量占位符（如 `{customer_name}`）；  
- 模板支持按名称查找与渲染；  
- 可在 Agent 或对话中直接引用模板名称执行聊天补全。  

> 系统级模板为公共资产，租户级模板仅限本租户访问。

### 模型与提供商管理  
系统内置多个 AI 提供商（如智谱 GLM、Stability AI、Runway、快影 Kling），每种提供不同模型与服务类型：

- 模型别名（Aliased Model）可映射真实模型名称，便于统一调用；  
- 每个提供商可独立配置基础地址、API 密钥与优先级；  
- 支持多提供商并行调度，提升容错与可用性。  

> 所有请求通过统一网关（AiGatewayService）分发至对应提供商。
