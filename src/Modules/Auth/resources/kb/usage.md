# 第三方认证使用手册

## 模块简介

本模块提供完整的第三方认证能力，支持社交登录（如微信、支付宝）、企业微信 OAuth、SSO（单点登录）集成及多因素认证（MFA），帮助租户实现安全、便捷的用户身份管理。通过该模块，运营人员可配置多种登录方式，管理用户权限与认证策略，保障系统访问安全。

主要解决以下问题：
- 用户可通过微信、支付宝等常用账号快速注册/登录，提升转化率；
- 支持企业级 SSO 集成，实现与外部身份提供商（IdP）统一认证；
- 提供 MFA 多因素验证机制，增强账户安全性；
- 支持对用户绑定的第三方账号进行管理与解绑；
- 为管理员提供角色权限控制与登录行为审计功能。

## 核心功能

### 社交登录与 OAuth 集成

支持主流平台的 OAuth 接入，包括：
- 微信网页授权（WeChat Web）
- 支付宝 OAuth（Alipay）
- 企业微信 OAuth（WeChat Work）

**操作说明：**
- 在租户后台配置对应平台的 App ID、密钥等参数；
- 用户在前端点击“微信登录”或“支付宝登录”按钮后，系统将跳转至对应平台授权页面；
- 授权成功后，系统自动获取用户信息并创建或关联账户；
- 用户可在个人资料页查看已绑定的第三方账号列表，并选择解绑。

> 注：所有 OAuth 登录流程均通过公开路由 `/api/v1/auth/{provider}/redirect` 和 `/api/v1/auth/{provider}/callback` 实现。
>
> **统一回调域（平台级虚拟 IDP）**：平台启用 `OAUTH_CALLBACK_DOMAIN`（如 auth.neihang.com）后，回调地址固定为 `https://{callback_domain}/api/v1/auth/{provider}/callback`（如 `https://auth.neihang.com/api/v1/auth/wechat/callback`），与租户自定义域名无关——租户在微信/支付宝后台只需配置一次回调域，改域名不断登录；未启用时按租户域名自动推导。
>
> 判断当前是否启用：租户 OAuth 配置页展示的「回调地址」若为 `{callback_domain}` 域即为启用（console 页面只读展示）。

### SSO 单点登录集成

支持 SAML 2.0 与 OIDC 协议的 SSO 集成，适用于企业级身份中心对接。

**功能包括：**
- 创建、编辑、删除 SSO 提供方；
- 配置 IdP 的元数据地址、证书、跳转 URL 等关键参数；
- 启用 SSO 后，用户可通过企业身份中心一键登录；
- 支持属性映射，将 IdP 返回的字段（如邮箱、姓名）映射到系统用户模型。

**操作路径：**
- 管理员进入管理后台，通过 `/auth/sso/providers` 接口管理 SSO 提供方；
- 可通过 `GET /auth/sso/providers` 查看当前配置；
- 使用 `POST /auth/sso/providers` 新增或更新 SSO 配置；
- 删除时调用 `DELETE /auth/sso/providers/{name}`。

### 多因素认证（MFA）

为用户账户提供额外安全保障，支持以下验证方式：
- TOTP（基于时间的一次性密码，生成二维码扫码绑定）；
- 邮箱验证码；
- 短信验证码；
- 恢复码（一次性使用，用于紧急情况）。

**用户可执行的操作：**
- 在个人设置中开启 MFA；
- 绑定多个设备（如手机、邮箱），并设置主设备；
- 重命名设备名称便于识别；
- 生成并保存恢复码（仅显示一次）；
- 查看当前活跃会话，强制下线其他设备；
- 解绑不再使用的设备。

> 所有 MFA 相关操作通过 `/mfa/*` 路由完成，用户可在租户控制台自行管理。

### 用户权限与角色管理（RBAC）

管理员可对系统内用户进行角色分配与权限控制。

**核心能力：**
- 创建自定义角色（如“运营专员”、“财务主管”）；
- 为角色分配具体权限（如“修改设置”、“导出数据”）；
- 将角色分配给特定用户成员；
- 删除不再使用的角色。

**管理入口：**
- 通过 `/auth/roles` 获取角色列表；
- 使用 `POST /auth/roles` 创建新角色；
- 通过 `PUT /auth/roles/{roleId}/permissions` 更新角色权限；
- 使用 `DELETE /auth/roles/{roleId}` 删除角色；
- 通过 `POST /auth/members/{userId}/role` 为用户分配角色。

> 权限控制依赖 RBAC 中间件，需具备 `rbac.manage` 权限方可操作。

---

### 用户资料与账户管理

用户可自主维护个人信息与安全设置。

**可操作项包括：**
- 修改昵称、头像、联系方式；
- 更改登录密码；
- 查看并解绑已绑定的第三方账号（如微信、支付宝）；
- 补充未填写的联系方式（如邮箱、手机号），用于后续找回密码或接收通知；
- 发送邮箱验证码以完成绑定。

> 所有操作通过 `/auth/profile` 和 `/auth/oauth-bindings` 等接口实现。

## 常见操作流程

### 1. 开启微信登录
1. 进入租户后台，导航至 OAuth 配置页面；
2. 点击“启用微信登录”，填写 AppID 与 AppSecret；
3. 保存配置后，前端页面将自动显示“微信登录”按钮；
4. 用户点击后跳转至微信授权页，授权完成后自动登录或注册。

### 2. 配置 SSO 企业登录
1. 管理员进入 `/auth/sso/providers` 接口；
2. 点击“新增 SSO 提供方”，选择类型（SAML 或 OIDC）；
3. 填写 IdP 的元数据地址、证书内容、客户端密钥等信息；
4. 保存后，系统生成 SSO 登录链接；
5. 将链接提供给企业用户，即可通过企业账号登录系统。

### 3. 为用户开启 MFA
1. 用户登录后进入个人设置；
2. 选择“多因素认证”选项；
3. 选择验证方式（如 TOTP）；
4. 扫描二维码完成设备绑定；
5. 输入生成的验证码确认绑定成功；
6. 系统提示生成恢复码，请妥善保存。

### 4. 解绑第三方账号
1. 用户进入“账户安全”设置；
2. 查看“已绑定账号”列表；
3. 点击“解绑”按钮；
4. 系统弹窗确认操作；
5. 成功后该账号将不再关联当前账户。

## 相关配置说明

### 租户级 OAuth 配置
- 配置路径：`/tenant/auth/oauth/config`
- 支持配置的平台：微信、支付宝、企业微信
- 需要填写：App ID、App Secret、回调地址等
- 修改后需重新测试登录流程

### 租户邮件 SMTP 配置
- 配置路径：`/tenant/auth/mail/config`
- 包括：SMTP 地址、端口、用户名、密码、发件人邮箱
- 支持发送测试邮件以验证配置有效性

### SSO 提供方配置
- 必填字段：名称、类型（SAML/OIDC）、IdP 元数据地址、证书、客户端密钥
- 支持动态启用/禁用
- 状态变更后立即生效

### MFA 设备与恢复码管理
- 每个用户可绑定多个 MFA 设备；
- 恢复码仅在生成时可见，不可重复获取；
- 设备可重命名、设为主设备、解绑；
- 支持批量强制下线所有会话。

> 所有配置变更均通过 API 接口完成，无需重启服务。
