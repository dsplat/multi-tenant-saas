# 计费核心使用手册

## 模块简介  
计费核心模块负责管理租户的订阅生命周期、积分与配额使用、支付流程及财务记录。通过该模块，运营人员可实现对订阅计划的配置、租户订阅状态的监控与变更、积分充值与消耗追踪、以及发票开具与支付对账等关键操作。本模块解决的核心问题包括：统一管理多租户的付费策略、自动化处理订阅续费与变更、支持多支付渠道集成、保障财务数据可追溯性，并为成本分析与风控提供底层支撑。

## 核心功能  

### 1. 订阅计划管理（管理员）  
用于创建、编辑、删除和查看所有可用的订阅计划。  
- 可设置计划名称、显示名、描述、价格（月/年）、试用天数、功能列表与使用限制。  
- 支持启用/禁用计划，调整排序优先级。  
- 所有变更需通过权限控制（`subscription.manage`）执行。  
- 提供接口 `/billing/plans` 与 `/billing/plans/{planId}` 查看计划详情。

### 2. 租户订阅管理（租户后台）  
租户可在自身控制台完成订阅相关操作：  
- 查看当前订阅状态（是否在试用期、所属计划、到期时间）。  
- 申请订阅新计划（支持按比例计算差价）。  
- 取消当前订阅（到期后自动降级为免费版）。  
- 变更现有计划（支持跨档位升级或降级）。  
- 查询历史订阅记录（含变更原因、金额、生效时间）。  
- 相关接口路径：`/tenants/{tenantId}/subscription`、`/tenants/{tenantId}/subscription/change` 等。

### 3. 积分账户管理  
支持对租户积分账户进行全链路管理：  
- 查看账户余额、已充值总额、已消费额度、有效期等信息。  
- 支持手动充值（需具备权限），并生成交易记录。  
- 可查看积分流水明细（来源、类型、金额、时间）。  
- 支持批量充值操作（仅限管理员）。  
- 接口路径：`/tenants/{tenantId}/credits`、`/credits/batch-recharge`。

### 4. 配额与用量监控  
实时掌握租户资源使用情况：  
- 查看当前配额设定（如文本生成次数、图像生成数量、视频时长等）。  
- 查询实际用量（按周期聚合），判断是否超限。  
- 支持动态负载调整下的速率限制控制。  
- 接口路径：`/tenants/{tenantId}/quotas`、`/tenants/{tenantId}/quotas/usage`。

### 5. 发票与财务记录  
实现从开票到付款的全流程管理：  
- 创建发票（支持草稿、已开具、已作废、已取消状态）。  
- 开具发票并标记为“已付”或“作废”。  
- 生成发票 PDF 文件供下载。  
- 查询指定租户、时间段或状态的发票列表。  
- 支持按租户、时间、状态筛选查询。  
- 接口路径：`/invoices`、`/tenants/{tenantId}/invoices`。

### 6. 支付与催收管理  
保障支付流程顺畅与风险可控：  
- 支持多种支付方式接入（PayPal、Stripe、微信支付、支付宝、银联）。  
- 自动触发支付回调验证与订单对账。  
- 处理支付失败场景，发送到期提醒通知。  
- 对长期未支付租户执行暂停操作。  
- 支持退款流程（全额或部分），并处理退款回调。  
- 提供支付安全检查机制（密码验证、限额控制、风控检测）。  
- 接口路径：`/payment-orders`、`/pay/callback`、`/dunning/process-failed-payment`。

### 7. 成本与盈亏分析  
为运营决策提供数据支持：  
- 按租户维度归集基础设施、AI服务、第三方服务的成本。  
- 生成月度成本报表，支持趋势预测。  
- 分析租户盈亏状况，辅助定价策略优化。  
- 接口路径：`/costs/report/monthly`、`/costs/profit-loss`。

## 常见操作流程  

### 流程一：新增订阅计划（管理员）  
1. 进入管理员后台，导航至「计费」模块。  
2. 点击「订阅计划管理」，进入计划列表页。  
3. 点击「新建计划」按钮，填写计划名称、价格、功能描述、试用天数等字段。  
4. 设置功能限制（如 AI 文本生成量、图像生成次数等）。  
5. 保存后，该计划将对外可见，租户可选择订阅。

### 流程二：租户订阅新计划  
1. 登录租户控制台，进入「计费」页面。  
2. 查看当前订阅状态与可用计划列表。  
3. 选择目标计划，点击「立即订阅」。  
4. 系统自动计算差价（如有），跳转至支付页面。  
5. 完成支付后，订阅立即生效，原计划自动失效。

### 流程三：租户变更订阅计划  
1. 在租户控制台的「订阅管理」中，点击「变更计划」。  
2. 选择目标计划，系统自动计算按比例退补金额。  
3. 确认变更信息，提交请求。  
4. 若需补款，跳转支付流程；若需退款，系统发起退款流程。  
5. 变更完成后，更新订阅记录并同步至历史日志。

### 流程四：管理员批量充值积分  
1. 进入管理员后台「积分管理」界面。  
2. 选择多个租户，填写充值金额与备注。  
3. 提交批量充值请求。  
4. 系统生成多条充值记录，对应租户账户余额增加。

### 流程五：开具发票  
1. 在租户财务记录中找到待开票的订单或订阅记录。  
2. 点击「创建发票」，填写发票抬头、税号等信息。  
3. 系统自动生成发票内容（含税费、金额、项目明细）。  
4. 保存为草稿或直接开具。  
5. 发票状态更新为“已开具”，可下载 PDF 文件。

## 相关配置说明  

- **支付配置**：每个租户可独立配置支付方式（微信、支付宝、Stripe、PayPal、银联），需通过 `updatePaymentConfig` 接口维护。  
- **税务规则**：支持按区域设置税率，系统根据租户所在地区自动匹配适用税率规则。  
- **自动充值**：可在积分账户中开启自动充值功能，当余额低于阈值时自动触发充值。  
- **催收策略**：系统定期扫描即将到期或已过期的订阅，自动发送提醒邮件，并在逾期后执行暂停操作。  
- **风控策略**：支付行为受单笔限额、日累计限额、失败频率等多重约束，异常行为将被记录并告警。  

> 注：所有配置项均通过 API 或后台界面进行管理，具体字段与取值范围以数据库模型为准。
