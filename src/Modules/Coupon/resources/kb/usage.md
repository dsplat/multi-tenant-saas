# 优惠券系统使用手册

## 模块简介  
优惠券系统用于支持企业通过创建优惠券模板、批量发放优惠券、核销管理及裂变分享等能力，实现对用户消费行为的激励与引导。该模块可帮助运营人员灵活配置优惠策略，提升用户转化率与活跃度。系统支持租户级开关控制，确保各租户独立管理自身优惠活动。

---

## 核心功能  

### 1. 优惠券模板管理  
通过模板统一定义优惠券的通用规则，包括类型（如折扣、满减）、金额、有效期、适用范围等。  
- 创建模板：设定优惠券基础属性，如名称、描述、优惠类型、金额、适用条件等。  
- 编辑与删除模板：修改或移除已存在的模板，支持启用/停用状态切换。  
- 模板生命周期管理：模板可被激活或停用，影响基于该模板生成的优惠券是否可用。

### 2. 优惠券生成与发放  
基于已创建的模板，快速生成并分发优惠券至目标用户。  
- 从模板生成优惠券：批量生成指定数量的优惠券码，并自动关联模板信息。  
- 批量发放：将生成的优惠券定向发送给指定用户列表，支持记录发放来源与批次信息。  
- 发放方式：可通过系统后台直接操作完成，无需手动逐个录入。

### 3. 优惠券核销与验证  
在订单结算环节，系统支持实时校验优惠券有效性并完成核销。  
- 校验接口：验证优惠券是否在有效期内、是否已被使用、是否满足最低消费门槛等。  
- 核销接口：当用户提交订单时调用，确认优惠券可使用后将其标记为已使用，并记录使用详情。  
- 使用记录查询：查看某张优惠券的详细使用历史，包括使用时间、用户、订单等信息。

### 4. 优惠券统计分析  
提供多维度数据视图，辅助评估优惠活动效果。  
- 使用统计：查看每张优惠券的总使用次数、已用数量、剩余可用数。  
- 活动表现分析：获取优惠券整体使用趋势、覆盖用户范围、带来的实际减免金额等数据。

### 5. 裂变分享功能  
支持用户间传播优惠券，实现“邀请好友得券”式增长。  
- 分享生成：用户点击分享按钮后，系统生成唯一分享链接并记录分享关系。  
- 接受分享：被分享人点击链接后，系统自动判定其身份并发放对应优惠券。  
- 分享记录查询：查看所有分享行为的完整轨迹，包括分享人、接收人、分享时间、状态等。

## 常见操作流程  

### 流程一：创建并发放优惠券  
1. 进入优惠券模板管理页面，点击“新建模板”，填写模板名称、优惠类型、金额、有效期等信息。  
2. 保存模板后，进入“从模板生成优惠券”功能，选择该模板并设置需生成的数量。  
3. 系统自动生成优惠码并持久化存储。  
4. 选择“批量发放”功能，上传用户列表或手动输入目标用户ID，确认后完成发放。  
5. 可通过“使用记录”或“统计”功能追踪发放后的使用情况。

### 流程二：发起裂变分享活动  
1. 在模板管理中创建一个适用于分享的优惠券模板（如“新用户专享券”）。  
2. 启用该模板并生成一批优惠券。  
3. 用户在前端点击“分享”按钮，系统生成带唯一标识的分享链接。  
4. 被分享人点击链接后，系统识别其身份并触发“接受分享”流程，向其发放优惠券。  
5. 分享人与接收人均可获得奖励，系统记录完整的分享链路。

### 流程三：核销与验证优惠券  
1. 用户在下单时输入优惠码，系统调用 `/validate` 接口进行合法性检查。  
2. 若校验通过，系统调用 `/redeem` 接口完成核销，并更新优惠券使用计数。  
3. 订单系统根据返回结果计算最终支付金额，同时记录本次使用详情于 `coupon_usage` 表中。

## 相关配置说明  

- **租户级开关**：该模块支持租户独立启用或禁用，由管理员在租户设置中控制。若关闭，则该租户无法使用任何优惠券相关功能。  
- **权限控制**：所有接口均绑定 RBAC 权限，运营人员需具备相应权限方可执行操作，如 `coupon.view`（查看）、`coupon.create`（创建）、`coupon.update`（编辑）等。  
- **数据归属**：所有优惠券、模板、分享记录均按租户隔离，确保数据安全与独立性。  
- **字段说明**：  
  - `code`：优惠券唯一编码，由系统生成。  
  - `is_template`：标识是否为模板，用于区分普通优惠券与模板。  
  - `template_id`：关联所属模板，用于继承模板配置。  
  - `metadata`：扩展字段，可用于存储自定义元数据，如活动来源、渠道标签等。  
  - `status`（在 CouponShare 表中）：表示分享状态，如待接受、已接受、已失效等。  

> 注：本系统不包含默认有效期、配额上限、最大发放数量等硬性限制，具体数值由业务配置决定，无固定默认值。
