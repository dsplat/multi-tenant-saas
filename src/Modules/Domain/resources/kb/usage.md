# 自定义域名管理使用手册

## 模块简介

自定义域名管理模块用于支持租户绑定自有域名，实现品牌化访问。该模块提供租户域名的申请、审批、验证与状态管理功能，同时支持平台级保留域名黑名单配置，防止敏感或高风险域名被滥用。系统可自动检查域名是否完成ICP备案（如启用），并生成Nginx白名单配置以保障安全接入。

本模块主要解决以下问题：
- 租户无法使用自有域名访问其业务系统；
- 域名归属权未验证导致安全风险；
- 缺乏统一的域名准入与备案合规机制；
- 无法为无独立域名的租户提供子域名访问能力。

## 核心功能

### 租户域名绑定与管理

租户可通过系统提交自有域名申请，管理员可在后台进行审核与配置。支持添加、修改、删除租户绑定的域名，所有操作均需具备相应权限。

- **新增域名**：租户提交域名后，系统记录待审状态，等待管理员审批。
- **修改域名**：已绑定域名可更新为新域名，需重新走审批流程。
- **删除域名**：移除租户当前使用的域名，解除绑定关系。
- **状态追踪**：每个域名具有明确状态（如待审批、已批准、已拒绝），便于运营监控。

### 域名归属验证

为确保租户对所申请域名拥有合法控制权，系统提供文件验证机制。通过在指定路径下放置验证文件，确认域名所有权。

- **生成验证 Token**：系统生成唯一验证令牌，供租户配置至域名根目录。
- **执行验证**：系统通过HTTP请求访问指定路径，检查是否存在对应文件，验证成功则标记为“已验证”。
- **查看验证指引**：系统提供详细的验证步骤说明，包括文件路径、内容格式等，帮助租户正确配置。

### ICP 备案状态检查（可选）

若系统配置开启ICP备案检查功能，系统将自动检测租户申请域名的备案状态。仅当备案信息有效时，域名方可进入最终批准状态。

- 该功能依赖外部接口调用，具体实现由服务层封装；
- 运营人员无需手动干预，系统自动判断并记录备案结果。

### 平台保留域名黑名单管理

平台可维护一组禁止被租户使用的保留域名列表（如 `admin.com`、`login.com` 等），防止恶意注册或混淆。

- 支持全量替换更新保留域名列表；
- 所有新申请域名将自动与黑名单比对，匹配则拒绝申请；
- 黑名单由平台管理员维护，仅限具备管理权限的用户操作。

### 子域名访问支持

系统支持为无独立域名的租户提供通配子域名访问能力，例如：`{slug}.dsplat.com`。

- 通过租户标识符（slug）动态路由至对应租户；
- 需配合DNS、SSL证书及Nginx配置启用；
- 可通过配置禁用该功能。

## 常见操作流程

### 1. 租户申请自定义域名

1. 租户登录系统，在个人设置或租户管理界面提交自有域名；
2. 系统生成待审批状态，并通知管理员；
3. 管理员在后台查看待处理申请，进入审批流程。

### 2. 管理员审批域名申请

1. 登录系统后台，进入域名管理区域；
2. 查看待审批的域名列表，包含申请时间、租户信息、域名详情；
3. 点击“批准”按钮，系统触发后续验证流程；
4. 若不符合要求，点击“拒绝”，填写拒绝原因并提交。

### 3. 完成域名归属验证

1. 管理员批准后，系统生成验证Token；
2. 向租户提供验证指引，包括：
   - 验证文件路径（如 `/.well-known/verify.txt`）
   - 文件内容（即生成的Token）
3. 租户将文件上传至其域名根目录；
4. 系统定时轮询验证，确认文件存在后，标记为“已验证”；
5. 验证成功后，域名进入可生效状态。

### 4. 更新平台保留域名列表

1. 管理员进入保留域名管理页面；
2. 查看当前黑名单列表；
3. 输入新的保留域名列表（逗号分隔或换行分隔）；
4. 提交更新，系统覆盖原有列表；
5. 新增域名立即生效，后续申请将自动拦截。

### 5. 启用子域名访问（适用于无独立域名租户）

1. 确保系统配置中 `wildcard_base` 不为 null；
2. 确认DNS已配置 `*.dsplat.com` 指向服务器IP；
3. 确保SSL证书支持通配符；
4. 确保Nginx配置包含 `server_name *.dsplat.com`；
5. 租户创建时系统自动分配子域名（如 `tenant1.dsplat.com`）；
6. 用户通过子域名访问系统，系统根据slug定位租户。

## 相关配置说明

### 平台域名配置

- `platform_domains.admin`：平台管理后台域名，默认为 `admin.example.com`；
- `platform_domains.app`：平台主应用域名，默认为 `app.example.com`；

> 注：实际值由环境变量 `PLATFORM_ADMIN_DOMAIN` 和 `PLATFORM_APP_DOMAIN` 控制。

### 子域名基础域名

- `wildcard_base`：通配子域名的基础域名，如 `dsplat.com`；
- 若设为 `null`，则关闭子域名访问功能；
- 该配置影响所有无独立域名的租户访问方式。

### ICP 备案检查开关

- `icp_check_enabled`：是否开启ICP备案状态检查；
- 默认为 `false`，开启后系统将自动校验域名备案状态；
- 仅在启用状态下，域名审批流程中会包含备案状态判断。

### Nginx 配置路径

- `nginx_map_file`：Nginx白名单映射文件路径，用于限制允许的域名；
- `ssl_nginx_map_file`：SSL证书映射配置文件路径；
- 以上路径需确保系统有读写权限，且与实际部署环境一致。

### SSL证书路径

- `ssl_certs_path`：存放SSL证书文件的目录路径；
- 用于生成和管理租户域名对应的SSL证书配置。

> 所有配置项均通过环境变量注入，建议在部署时根据实际环境调整。
