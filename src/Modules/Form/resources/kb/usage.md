# 表单构建器使用手册

## 模块简介

表单构建器模块用于支持租户在系统中快速创建、管理及收集表单数据。通过拖拽式设计界面，运营人员可灵活配置表单结构，包括字段类型、必填项、验证规则等，实现高效的数据采集。该模块支持公开表单提交（无需登录）与受控表单提交（需登录），并提供提交记录查询、统计分析与数据导出功能，适用于问卷调研、用户注册、意见反馈等多种业务场景。

本模块具备租户级开关控制能力，可根据实际需要开启或关闭表单功能，确保资源按需分配。

## 核心功能

### 1. 表单创建与管理

运营人员可在控制台中创建新的表单，设置表单标题、描述、状态（启用/禁用）、提交时间范围（开始与结束时间）、提交按钮文字及提交成功后的提示信息。表单可设定为公开或私密，若设为公开，则允许未登录用户提交；若设为私密，则仅限已登录用户提交。

每个表单可配置多个字段，支持文本输入、单选、多选、下拉框、日期选择、文件上传等多种常见字段类型。字段可设置是否必填、默认值、占位符、排序顺序及自定义校验规则。

### 2. 表单提交与数据收集

当表单发布后，用户可通过指定链接访问并填写提交。对于公开表单，用户可直接提交数据；对于私密表单，系统会校验用户登录状态。提交过程由后端接口统一处理，确保数据安全与完整性。

所有提交记录均被保存至数据库，包含提交时间、用户ID（如有）、IP地址、浏览器信息等元数据，便于后续追溯与分析。

### 3. 提交记录查看与管理

运营人员可查看特定表单的所有提交记录，包括每条提交的完整数据内容、提交时间、来源IP及设备信息。该功能支持按时间范围筛选，帮助快速定位特定时间段内的数据。

### 4. 提交数据统计分析

系统提供基于表单提交数据的统计视图，展示各字段的填写情况、选项分布、提交趋势等可视化信息。统计结果可用于评估活动效果、优化表单设计或生成报告。

### 5. 数据导出

支持将表单的全部提交数据以标准格式（如 CSV 或 Excel）导出。导出文件包含所有字段的原始数据及提交元信息，便于离线分析、存档或与其他系统对接。

## 常见操作流程

### 创建新表单

1. 进入表单管理页面（如系统提供相关菜单路径）；
2. 点击“新建表单”按钮；
3. 输入表单标题与描述；
4. 设置表单状态、提交时间范围（开始与结束时间）；
5. 决定是否公开表单（影响提交权限）；
6. 在表单编辑区，通过拖拽方式添加字段，配置字段标签、类型、是否必填、默认值、校验规则等；
7. 配置提交按钮文字与成功提示语；
8. 保存表单，完成创建。

### 发布并分享表单

1. 确认表单已处于启用状态；
2. 若为公开表单，复制其公共提交链接，通过邮件、短信、网页等方式分发；
3. 若为私密表单，通过内部渠道通知目标用户，并确保其已登录系统；
4. 可在表单详情页查看提交入口链接。

### 查看提交记录

1. 在表单列表中点击目标表单名称进入详情页；
2. 切换至“提交记录”标签页；
3. 查看所有提交条目，包括提交时间、用户信息（如有）、IP地址、设备信息及完整数据内容；
4. 可根据需要筛选时间范围或搜索特定提交。

### 获取统计信息

1. 在表单详情页中进入“统计分析”模块；
2. 查看各字段的填写分布、选项选择比例、提交趋势图表；
3. 支持查看整体提交量、有效提交数、重复提交情况等关键指标。

### 导出提交数据

1. 在表单详情页中点击“导出数据”按钮；
2. 系统生成数据文件，支持下载；
3. 下载后可使用 Excel、CSV 工具打开，进行进一步分析。

## 相关配置说明

- **租户级开关**：该模块支持租户维度的启用与禁用。若租户关闭此功能，则无法创建或管理任何表单。
- **表单状态控制**：表单可设置为启用或禁用状态。禁用状态下，用户无法提交数据，但历史提交记录仍可查看。
- **提交时间范围**：可设置表单的有效提交时间区间（起始与截止时间）。超出时间范围后，系统将拒绝新提交。
- **提交限制**：表单可配置提交次数上限（如设置为 100 次），超过后将不再接受新提交。具体数值由运营人员在创建时设定。
- **字段配置灵活性**：支持自定义字段键名（field_key）、标签（label）、类型（field_type）、验证规则（validation_rules）及附加元数据（metadata），满足复杂业务需求。
- **安全性保障**：公开表单提交接口设有请求频率限制（如每分钟最多 10 次），防止恶意刷单行为。
