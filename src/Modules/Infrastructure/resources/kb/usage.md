# 基础设施使用手册

## 模块简介  
基础设施模块为 SaaS 平台提供核心支撑能力，涵盖系统配置、安全策略、资源管理与功能控制。该模块帮助运营人员统一管理平台级与租户级的配置项，实现对功能开关、IP 白名单、品牌化设置、数据保留策略等关键能力的集中管控。通过本模块，可保障系统稳定性、合规性及多租户环境下的隔离与安全。

## 核心功能  

### 功能开关管理  
用于在系统或租户级别启用或禁用特定功能模块。支持动态开启/关闭功能，适用于灰度发布、临时维护或按需开放新特性。可通过接口或控制台查看当前所有功能的状态，并进行状态切换。

### Webhook 管理  
支持创建、更新、测试和删除 Webhook。可用于接收系统事件通知（如订单创建、用户注册、支付成功等），并推送至外部服务。每条 Webhook 可配置事件类型、目标 URL、签名密钥，并支持手动重试发送失败的事件。

### IP 白名单管理  
用于限制访问系统的 IP 地址范围。可为租户配置白名单规则，仅允许指定 IP 或 CIDR 段访问其服务。支持添加、删除和启用/禁用白名单条目，增强租户访问安全性。

### 品牌配置管理  
支持自定义租户的品牌外观，包括上传 Logo、Favicon，设置主色调、辅助色、登录页样式及邮件模板。配置后将应用于租户的前端界面与邮件通知，实现品牌统一。

### 系统设置管理  
集中管理平台级系统参数，如通用配置项、加密字段、描述信息等。支持按分组维护配置，确保系统运行所需的基础参数一致性和可追溯性。

### 租户密钥管理  
为每个租户生成并管理加密密钥，用于保护租户数据的机密性。支持密钥轮换、导入 BYOK（自带密钥）、查看当前活跃密钥及历史密钥记录，保障数据加密生命周期管理。

### 数据保留策略管理  
定义不同类型数据的保留周期与清理方式。可为不同数据类型（如日志、文件、用户行为）设定保留天数、是否自动清理、清理策略及豁免标记，满足 GDPR 等合规要求。

### 模块管理  
管理平台内所有可插拔模块的启用与禁用状态。支持系统级模块管理（全局生效）以及租户级模块管理（按租户独立配置）。可查看模块列表、依赖关系、加载顺序，并根据需要启用或停用模块。

### 队列失败任务管理  
监控并处理异步任务队列中的失败任务。支持查看失败任务详情、批量重试、逐个重试、删除或清空全部失败任务，保障后台任务的可靠性与可恢复性。

## 常见操作流程  

### 1. 为租户启用一个功能模块  
- 进入模块管理界面；
- 找到目标租户；
- 在租户可用模块列表中选择待启用的功能模块；
- 点击“启用”按钮，系统将立即应用该模块的配置。

### 2. 添加一条 IP 白名单规则  
- 进入 IP 白名单管理页面；
- 点击“新增”；
- 输入要允许的 IP 地址或 CIDR 范围；
- 填写描述信息；
- 保存并启用规则。

### 3. 配置品牌化设置  
- 进入品牌配置管理页面；
- 选择目标租户；
- 上传 Logo 和 Favicon 文件；
- 设置主色调、辅助色；
- 自定义登录页样式与邮件模板；
- 提交更新。

### 4. 创建 Webhook 事件通知  
- 进入 Webhook 管理页面；
- 点击“新建 Webhook”；
- 选择触发事件类型（如用户注册、订单支付）；
- 输入目标回调地址；
- 生成并保存签名密钥；
- 测试连接有效性；
- 保存并激活。

### 5. 设置数据保留策略  
- 进入数据保留策略管理页面；
- 点击“新建策略”；
- 选择数据类型（如日志、附件）；
- 设置保留天数；
- 选择是否自动清理；
- 可选勾选“豁免”，防止被误删；
- 保存策略。

### 6. 重试失败队列任务  
- 进入队列失败任务管理页面；
- 查看失败任务列表；
- 选择单个任务或全选；
- 点击“重试”按钮；
- 系统将重新投递该任务。

## 相关配置说明  

- **权限控制**：所有操作均受 RBAC 权限体系约束，需具备对应权限（如 `setting.view`、`security.update`）方可执行。
- **数据存储**：相关配置信息存储于数据库表中，包括 `feature_flags`、`webhooks`、`ip_whitelist`、`branding_configs`、`system_settings`、`tenant_keys`、`retention_policies` 等。
- **租户上下文**：多数配置支持租户维度操作，即针对特定租户（tenant_id）进行读写，确保多租户环境下的独立性。
- **接口路径**：所有功能可通过 API 接口访问，路径前缀为 `/admin`（管理员）或 `/tenants/{tenantId}`（租户级），具体路径参考路由定义。
