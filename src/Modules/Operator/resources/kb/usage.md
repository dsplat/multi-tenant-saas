# 运营人员管理使用手册

## 模块简介

本模块用于管理平台及租户层级的运营人员，构建独立的运营账号体系。通过该模块，平台管理员与租户管理员可完成运营人员的创建、邀请、角色分配、状态控制与权限管理。核心功能包括：运营人员账户生命周期管理（注册、激活、启用/禁用）、跨租户权限映射、邀请流程闭环处理，以及多租户环境下的角色与归属关系维护。

该模块解决的核心问题包括：
- 实现运营人员与普通用户分离的独立身份体系；
- 支持平台级与租户级双重管理权限；
- 保障运营人员在不同租户间的权限隔离与灵活配置；
- 提供完整的邀请—接受—激活—授权流程支持。

## 核心功能

### 1. 运营人员全生命周期管理

平台管理员与租户管理员均可对运营人员进行增删改查操作，涵盖从创建到移除的完整生命周期。

- **创建与邀请**：通过“邀请”功能向指定邮箱发送邀请链接，被邀请人将收到邮件并完成注册与密码设置。
- **查看详情**：可查看任一运营人员的详细信息，包括姓名、联系方式、所属租户、当前状态、最后登录时间等。
- **更新资料**：修改运营人员的姓名、电话、头像等基本信息。
- **启用/禁用**：切换运营人员的激活状态，禁用后其无法登录系统，但保留所有历史数据。
- **移除账户**：永久删除运营人员账户及其关联记录。

### 2. 多租户权限映射管理

每个运营人员可被分配至一个或多个租户，并在不同租户中拥有独立的角色权限。

- **查看归属租户**：可查看某运营人员当前管理的所有租户列表。
- **添加至租户**：将已有运营人员加入新的租户，赋予其在该租户中的角色。
- **从租户移除**：将运营人员从某个租户中移除，自动停用其在该租户下的所有访问凭证。
- **角色变更**：为运营人员在特定租户中调整角色，实现细粒度权限控制。

### 3. 邀请流程闭环支持

提供完整的邀请—接受—激活流程，确保运营人员能安全、有序地加入系统。

- **发送邀请**：由管理员发起邀请，系统生成唯一邀请令牌并发送至目标邮箱。
- **重新发送邀请**：若邀请邮件未送达，可重复发送。
- **接受邀请**：被邀请人点击链接后进入注册页面，填写密码完成账户激活。
- **邮箱验证**：首次注册时需完成邮箱验证，确保账户真实性。

### 4. 账户安全与行为控制

系统内置基础安全机制，保障运营人员账户安全。

- **登录尝试限制**：多次错误登录将触发锁定机制，防止暴力破解。
- **密码变更记录**：记录每次密码修改时间，便于审计追踪。
- **登录日志**：保存每次登录时间，用于行为分析与异常检测。

## 常见操作流程

### 流程一：邀请新运营人员

1. 进入运营人员管理界面；
2. 点击“邀请”按钮；
3. 输入被邀请人的邮箱地址；
4. 选择其初始角色（如“运营管理员”、“运营专员”）；
5. 系统自动生成邀请链接并发送至该邮箱；
6. 被邀请人接收邮件后点击链接，完成注册与密码设置；
7. 账户激活成功后，可在系统中查看其状态为“已激活”。

> 注：邀请链接有效期由系统动态设定，无需手动配置。

### 流程二：将运营人员分配至新租户

1. 打开目标运营人员的详情页；
2. 查看其当前所属租户列表；
3. 点击“添加至租户”按钮；
4. 选择目标租户；
5. 为其在该租户中分配角色；
6. 系统自动建立关联关系，该运营人员即获得在该租户内的操作权限。

### 流程三：禁用或移除运营人员

1. 找到目标运营人员记录；
2. 点击“禁用”按钮，账户立即失效，无法登录；
   - 若需彻底清除，可执行“移除”操作，删除账户及所有相关数据；
3. 移除后，该运营人员在所有租户中的权限自动撤销。

### 流程四：重发邀请邮件

1. 在运营人员列表中找到对应记录；
2. 点击“重新发送邀请”按钮；
3. 系统将再次发送包含最新邀请链接的邮件；
4. 被邀请人可使用新链接完成注册流程。

## 相关配置说明

本模块不提供可配置的参数项（如数量上限、有效期、配额等），所有行为均基于默认规则执行。

- **邀请有效期**：由系统动态生成，无固定时长；
- **角色权限**：角色定义由系统预设，管理员仅可选择不可自定义；
- **登录限制策略**：基于请求频率的限流机制已内置于认证接口，无需额外配置；
- **租户开关**：本模块不可由租户自行开启或关闭，始终处于启用状态。

> 所有配置项均以代码逻辑实现，不对外暴露可编辑的配置入口。
