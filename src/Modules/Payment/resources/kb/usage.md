# 支付网关使用手册

## 模块简介

支付网关模块用于对接第三方独立支付平台（如馒头支付），为租户提供安全、可配置的在线支付能力。该模块支持支付订单创建、支付结果回调处理、退款发起与状态查询等功能，帮助运营人员管理租户的支付行为与资金流转。

本模块主要解决以下问题：
- 实现租户与外部支付平台之间的支付流程集成；
- 提供统一的支付配置入口，便于灵活启用或关闭支付功能；
- 支持多支付渠道（如微信、支付宝）的配置与管理；
- 保障支付数据的安全性与完整性，通过签名验证机制防止恶意请求。

## 核心功能

### 支付配置管理

可通过系统配置界面或接口调整支付网关的基础参数，包括支付网关地址、服务 ID、应用 ID、通知地址等。配置项支持动态更新，适用于不同租户的差异化支付需求。

> **注意**：配置变更后需确保相关支付平台已正确设置对应的异步通知地址，以保证支付成功后的回调正常触发。

### 支付订单管理

支持创建、查询和查看支付订单。运营人员可基于租户维度获取支付订单列表，查看订单详情，包括支付金额、状态、创建时间等信息。

- 创建支付订单：通过调用接口生成待支付订单，系统将自动调用 H5 预下单接口，返回支付链接或二维码。
- 查看订单详情：可查看任意支付订单的完整信息，包括支付方式、交易流水号、支付状态等。

### 退款操作与状态追踪

支持对已完成的支付订单发起退款申请，并实时查询退款进度。

- 发起退款：针对已支付订单，提交退款请求，系统将向第三方支付平台发送退款指令。
- 查询退款状态：可主动查询退款是否成功，获取退款结果反馈，便于后续财务核对。

### 回调处理与安全性保障

系统自动接收来自第三方支付平台的异步通知（如支付成功、退款完成），并进行验签处理，确保数据来源合法。所有回调均通过 `handleNotify()` 方法统一处理，避免重复处理或伪造通知。

## 常见操作流程

### 1. 启用支付功能

1. 进入系统配置中心，找到“支付模块”开关；
2. 将支付模块状态设为“启用”；
3. 确保 `payment.php` 配置文件中 `enabled` 字段为 `true`；
4. 保存配置后，租户侧将可访问支付相关功能。

### 2. 配置支付渠道

1. 在控制台或 API 接口路径 `/payments/config` 获取当前支付配置；
2. 根据实际使用的支付平台（如微信、支付宝），填写对应驱动（driver）的配置项；
3. 调用接口 `PUT /payments/config/{driver}` 更新配置，例如：
   - `driver=wechat`
   - 请求体包含 `app_id`, `secret`, `notify_url` 等必要字段；
4. 验证配置生效后，租户即可在前端发起支付请求。

### 3. 创建支付订单

1. 通过接口 `/tenants/{tenantId}/payment-orders` 或前端页面发起支付请求；
2. 提交订单信息（如金额、订单编号、商品描述）；
3. 系统调用 `createOrder()` 方法生成支付订单，并返回支付跳转链接或二维码；
4. 用户跳转至支付页面完成支付。

### 4. 处理退款申请

1. 在订单列表中定位目标支付订单；
2. 调用接口 `POST /tenants/{tenantId}/payment-orders/refund` 提交退款请求；
3. 传入原订单号及退款金额等必要信息；
4. 系统向第三方支付平台发起退款指令；
5. 可通过 `GET /tenants/{tenantId}/payment-orders/refund-status` 查询退款状态。

### 5. 查看支付订单汇总

1. 访问管理员接口 `/payments/orders` 获取所有租户的支付订单列表；
2. 可按时间、状态、订单号等条件筛选；
3. 点击具体订单编号，调用 `/payments/orders/{orderId}` 查看详细信息。

## 相关配置说明

### 支付核心配置项（`payment.php`）

| 配置项 | 说明 |
|--------|------|
| `gateway` | 第三方支付网关的接入地址，用于发起支付请求 |
| `service_id` | 服务唯一标识，由支付平台分配 |
| `password` | 服务访问密钥，用于身份认证 |
| `app_id` | 应用唯一标识，用于区分不同业务系统 |
| `notify_url` | 异步通知地址，支付平台将回调此地址通知支付结果 |
| `return_url` | 同步跳转地址，支付完成后用户浏览器跳转的目标页 |
| `show_url` | 支付结果展示页地址，用于前端展示支付状态 |
| `enabled` | 是否启用支付模块，布尔值，影响功能可用性 |

> 所有配置项均可通过环境变量覆盖，建议在生产环境中使用 `.env` 文件管理敏感信息。
