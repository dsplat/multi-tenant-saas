# 平台工具使用手册

## 模块简介

平台工具模块为系统运营提供核心管理能力，涵盖租户申请全流程管理、系统配置维护、功能开关控制及公开信息展示。该模块主要解决以下业务问题：

- 统一管理新租户的申请与审批流程，确保入驻合规；
- 支持动态配置系统参数（如邮件、积分价格等），适应不同运营策略；
- 提供灵活的功能开关机制，支持灰度发布与 A/B 测试；
- 向外部用户提供申请进度查询和表单字段配置接口，提升用户体验；
- 实现系统关键配置的导出与批量导入，便于迁移与备份。

本模块不支持租户自行开启或关闭，所有操作需由管理员或具备权限的 Operator 执行。

## 核心功能

### 租户申请与审批管理

通过本功能可集中处理新租户的入驻申请。管理员可在后台查看所有待审申请，查阅申请人提交的信息，并完成审批或拒绝操作。

- **申请列表查看**：管理员可进入申请管理界面，浏览全部租户申请记录，包括申请编号、企业名称、行业、规模、联系人信息等。
- **申请详情查看**：点击任意申请条目，可查看完整申请内容，包括填写的字段信息及历史审核备注。
- **审批通过**：管理员确认申请信息无误后，可执行“通过”操作。系统将自动创建对应租户账户、关联 Operator 信息，并触发通知邮件发送。
- **拒绝申请**：若申请不符合要求，管理员可选择“拒绝”，并填写拒绝原因，申请人将收到反馈。

### 申请字段配置管理

运营人员可根据实际需求自定义租户申请表单的字段内容与显示逻辑。

- **字段配置查看**：可查看当前生效的申请字段配置，了解哪些信息项对申请人开放。
- **字段配置更新**：支持动态调整申请表单中各字段的可见性、必填性等属性，无需修改代码即可响应业务变化。

### 系统配置管理

集中管理平台运行所需的基础配置项，保障系统稳定与个性化设置。

- **系统参数配置**：可修改系统级参数，如默认平台名称、LOGO、页脚文字等。
- **邮件服务配置**：配置邮件发送相关参数（如 SMTP 地址、端口、账号密码），并支持测试连接是否正常。
- **积分价格配置**：设定平台内积分的单价，用于后续计费场景。
- **Dify 集成配置**：配置与 Dify 平台的对接参数，支持测试连接有效性。
- **配置导出与导入**：支持将全部系统配置导出为文件，也支持从文件批量导入配置，适用于多环境同步或灾备恢复。

### 功能开关管理

实现对系统功能的精细化控制，支持灰度发布、A/B 测试及依赖管理。

- **开关状态管理**：可启用或禁用特定功能模块，影响范围覆盖全平台或指定租户/用户。
- **灰度发布控制**：设置功能在特定比例用户中可见，逐步推广新功能。
- **分组测试支持**：配置 A/B 测试分组，用于对比不同功能版本的表现。
- **租户与用户级覆盖**：为个别租户或用户单独设置功能开关状态，实现差异化体验。
- **依赖关系检查**：在启用某功能前，系统会自动校验其依赖项是否已开启，避免配置错误。
- **变更历史追踪**：记录每次开关变更的操作日志，支持审计追溯。

### 公开信息与申请进度查询

为外部用户提供透明化服务，增强申请流程的可感知性。

- **申请进度公开查询**：申请人可通过申请编号，在公开页面实时查看申请所处状态（如待审核、已通过、已拒绝）。
- **申请表单字段公开获取**：前端可调用接口获取当前有效的申请字段配置，动态渲染表单，确保表单与后台一致。
- **站点公开配置获取**：获取平台名称、LOGO、注册状态、申请入口状态等公开信息，用于前端页面渲染。

## 常见操作流程

### 1. 审批新租户申请

1. 登录管理员后台，进入「租户申请」管理页面。
2. 查看申请列表，筛选待处理申请。
3. 点击某条申请记录，查看详细信息。
4. 若信息完整且符合标准，点击“通过”按钮。
5. 系统自动创建租户账户，并发送通知邮件。
6. 若申请存在问题，点击“拒绝”，填写拒绝理由后提交。

### 2. 更新申请表单字段

1. 进入「申请字段配置」管理页面。
2. 查看当前字段配置列表，确认需要调整的字段。
3. 修改字段的显示状态、是否必填等属性。
4. 保存更改，新配置立即生效。

### 3. 导出系统配置

1. 进入「系统配置」管理页面。
2. 点击“导出配置”按钮。
3. 系统生成包含所有配置项的文件，下载至本地。
4. 可用于备份或在其他环境导入。

### 4. 批量导入系统配置

1. 在「系统配置」管理页面，点击“导入配置”。
2. 上传之前导出的配置文件。
3. 系统验证文件格式后，自动应用所有配置项。
4. 操作完成后提示导入成功。

### 5. 发布新功能（灰度发布）

1. 进入「功能开关」管理页面。
2. 找到目标功能开关，点击编辑。
3. 设置灰度发布比例（如 10%）。
4. 可选配置 A/B 分组或租户级覆盖。
5. 保存后，仅部分用户将看到新功能。

## 相关配置说明

- **申请字段配置**：由 `ApplyFieldConfigController` 控制，配置内容决定前端申请表单的结构。
- **系统配置项**：存储于系统配置表中，通过 `SystemSettingService` 提供读写接口。
- **功能开关数据**：由 `FeatureFlagService` 管理，支持缓存加速与历史审计。
- **公开接口路径**：
  - `/public/apply-fields`：返回申请字段配置，供前端动态渲染表单。
  - `/public/apply/{code}`：根据申请编号返回申请状态。
  - `/public/site-config`：返回平台公开信息，用于首页渲染。
- **控制台菜单路径**：
  - `platform-apply`：位于控制台导航栏，路径为 `/apply`，用于提交新租户申请。
  - `platform-my-applications`：路径为 `/my-applications`，用于查看当前 Operator 的申请记录。
