# 插件管理使用手册

## 模块简介  
插件管理模块用于统一管理系统的可扩展功能组件（即“插件”）。通过该模块，运营人员可以对插件进行安装、卸载、启用与禁用等操作，实现对系统功能的灵活配置与动态调整。本模块解决的核心问题是：在不修改核心系统代码的前提下，按需引入或移除特定业务功能，支持系统功能的模块化与可维护性。

## 核心功能  

### 插件安装与卸载  
- **安装插件**：从系统可用插件列表中选择目标插件并执行安装操作，系统将完成文件部署及数据库初始化。  
- **卸载插件**：移除已安装的插件，系统会清理相关数据记录，并触发预设的清理钩子，确保环境干净。

### 插件启用与禁用  
- **启用插件**：激活已安装但处于禁用状态的插件，使其功能可被系统调用。  
- **禁用插件**：临时停用正在运行的插件，不影响其安装状态，适用于调试或临时关闭特定功能。

### 插件清单管理  
- **列出已安装插件**：查看当前系统中所有已安装插件的名称、状态及版本信息。  
- **扫描可用插件**：读取插件目录，获取所有可被识别的插件列表（包括未安装的），用于发现新功能组件。

### 插件依赖检查  
- 系统在安装或启用插件前，自动校验其依赖项是否满足，若存在缺失依赖则阻止操作并返回错误提示。

### 插件配置管理  
- **获取插件配置**：读取指定插件的当前配置内容。  
- **更新插件配置**：修改插件的运行参数，配置变更立即生效（具体生效范围取决于插件实现）。

## 常见操作流程  

### 安装新插件  
1. 通过系统接口调用 `GET /plugins` 获取当前已安装插件列表。  
2. 调用 `POST /plugins/{name}/scanAvailable` 扫描插件目录，获取所有可用插件清单。  
3. 确定目标插件名称后，发起 `POST /plugins/{name}/install` 请求，开始安装流程。  
4. 安装完成后，系统返回成功响应，插件进入“已安装”状态。

### 启用已安装插件  
1. 确认插件已安装但处于禁用状态。  
2. 发起 `POST /plugins/{name}/enable` 请求，激活该插件。  
3. 成功后，插件功能可在系统中正常调用。

### 禁用运行中的插件  
1. 选择正在运行的插件。  
2. 发起 `POST /plugins/{name}/disable` 请求，停止其功能执行。  
3. 插件状态变为“已禁用”，不再参与系统逻辑处理。

### 卸载不再使用的插件  
1. 确保插件当前处于“已禁用”状态。  
2. 发起 `POST /plugins/{name}/uninstall` 请求，启动卸载流程。  
3. 系统将删除插件相关数据记录，并执行清理钩子，完成彻底移除。

### 查看与修改插件配置  
1. 使用 `GET /plugins/{name}/config` 接口获取当前插件的配置内容。  
2. 若需修改，调用 `POST /plugins/{name}/config` 并传入新的配置值。  
3. 配置更新后立即生效，无需重启服务。

## 相关配置说明  
- 本模块无独立配置项，所有行为由系统默认规则控制。  
- 插件的生命周期钩子（如安装/卸载时的回调函数）由插件自身实现，运营人员无法直接干预。  
- 插件目录结构需符合系统规范，否则无法被扫描识别。  
- 依赖检查机制自动运行于安装与启用阶段，失败时将返回具体错误信息，建议根据提示排查依赖问题。
