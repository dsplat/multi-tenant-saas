# SSL 证书管理使用手册

## 模块简介

本模块用于管理租户自定义域名的 SSL 证书，支持证书上传、续期与删除操作，并自动同步至 Nginx 配置。通过该功能，运营人员可为租户配置安全的 HTTPS 访问能力，保障其自定义域名在公网环境下的通信加密。

该模块解决的核心问题包括：  
- 租户自定义域名无法启用 HTTPS 访问；  
- 证书过期后未及时更新导致服务中断；  
- 手动修改 Nginx 配置存在遗漏或错误风险。

模块具备租户级开关控制，可根据业务需要对特定租户启用或禁用 SSL 功能。

---

## 核心功能

### 1. 证书上传与绑定

运营人员可为指定租户上传 SSL 证书文件（包含公钥证书和私钥），系统将自动保存至服务器指定目录，并生成对应的 Nginx 配置映射。

- 支持上传 PEM 格式的证书文件；
- 上传后系统会验证证书有效性并记录状态；
- 证书信息将被持久化存储，便于后续查看与管理。

### 2. 证书续期操作

当租户证书即将到期或已过期时，可通过本模块发起续期流程。系统提供接口支持主动触发续期动作，确保服务持续可用。

- 续期操作不涉及证书内容变更，仅重新生成并部署配置；
- 系统会调用底层服务完成证书重载与 Nginx 配置刷新；
- 可用于应对证书自动续期失败或手动干预场景。

### 3. 证书删除与清理

运营人员可移除租户已绑定的 SSL 证书，系统将同步清理相关文件及 Nginx 配置项。

- 删除操作不可逆，请谨慎执行；
- 删除后对应域名将不再启用 HTTPS，恢复为 HTTP 访问；
- 系统会自动更新 Nginx 的 SSL 映射文件，确保配置一致性。

### 4. 证书状态查询

系统提供接口用于获取租户当前 SSL 证书的状态信息，包括证书有效期、是否启用、绑定域名等关键指标。

- 用于监控租户证书健康状况；
- 支持批量查询多个租户的证书状态；
- 可作为自动化巡检与告警的数据源。

### 5. Nginx 配置自动同步

每次证书操作完成后，系统将自动调用服务生成新的 Nginx SSL 映射文件，并由 systemd 监听机制触发 Nginx 重载。

- 无需人工干预重启 Nginx；
- 确保配置变更立即生效；
- 保证所有租户域名的 HTTPS 路由正确指向对应证书。

## 常见操作流程

### 流程一：为租户上传新 SSL 证书

1. 进入系统管理界面，定位到目标租户；
2. 调用 `POST /tenants/{tenantId}/ssl` 接口，提交证书文件（公钥证书 + 私钥）；
3. 系统接收并校验证书格式与完整性；
4. 证书文件写入服务器指定路径（如 `/app/ssl-certs`）；
5. 系统调用 `regenerateNginxMap()` 服务，更新 Nginx 配置；
6. 返回成功响应，证书状态标记为“已启用”。

> 注：若证书无效或格式错误，接口将返回错误信息，需重新上传。

---

### 流程二：为租户触发证书续期

1. 确认目标租户当前证书处于有效期内或即将过期；
2. 调用 `POST /tenants/{tenantId}/ssl/renew` 接口；
3. 系统调用 `renew()` 方法，执行续期逻辑；
4. 若续期成功，系统更新证书文件并刷新 Nginx 配置；
5. 返回续期结果，状态更新为“续期成功”；
6. 如续期失败，返回具体错误原因，建议检查证书来源或网络连接。

---

### 流程三：移除租户的 SSL 证书

1. 确定该租户不再需要 HTTPS 访问；
2. 调用 `DELETE /tenants/{tenantId}/ssl` 接口；
3. 系统执行 `removeCertificate()` 服务，删除证书文件；
4. 同步调用 `regenerateNginxMap()` 更新 Nginx 配置；
5. 返回删除成功响应，证书状态变为“已移除”；
6. 对应域名将停止使用 HTTPS，转为 HTTP 访问。

## 相关配置说明

### 证书存储路径配置

- 配置项：`ssl.certs_path`
- 默认值：`/app/ssl-certs`
- 作用：指定服务器上存放 SSL 证书文件的物理路径。
- 权限要求：
  - 该目录必须由 `www-data` 用户拥有；
  - 权限设置为 `750`，确保仅允许所属用户读写，其他用户只读；
  - 建议初始化命令如下：
    ```bash
    sudo mkdir -p /app/ssl-certs
    sudo chown www-data:www-data /app/ssl-certs && sudo chmod 750 /app/ssl-certs
    ```

### Nginx SSL 映射文件配置

- 配置项：`ssl.nginx_map_file`
- 默认值：`/app/ssl-certs/ssl-map.conf`
- 作用：定义 Nginx 中用于动态加载 SSL 证书映射关系的配置文件路径。
- 特性：
  - 文件由系统自动维护，无需手动编辑；
  - 由 systemd 的 path unit 监听目录变更，实现自动 reload；
  - 必须与证书目录位于同一路径下，以保证监听生效。

> 提示：若需修改路径，应在 `.env` 文件中设置 `SSL_CERTS_PATH` 和 `SSL_NGINX_MAP_FILE` 环境变量，确保路径一致且权限正确。
