# 短信服务使用手册

## 模块简介  
短信服务模块为租户提供完整的短信管理能力，涵盖短信模板创建与审核、批量及定时发送、发送结果统计、用户退订管理等功能。通过该模块，运营人员可高效完成营销通知、验证码下发等场景的短信触达，同时保障合规性与数据可追溯性。本模块支持租户级开关控制，确保功能启用与关闭灵活可控。

---

## 核心功能

### 短信模板管理  
用于创建、编辑、提交审核及查看短信模板。  
- 支持定义模板名称、唯一编码、内容正文、变量占位符（如`{code}`）等信息。  
- 可设置短信类型（如验证码、通知类）、发送渠道、签名名称。  
- 模板需提交审核后方可用于正式发送。  
- 提供预览功能，可实时查看模板内容在变量填充后的实际效果。

### 批量发送与定时发送  
支持向指定手机号列表群发短信，支持立即发送或设定时间发送。  
- 可选择目标类型（如全部用户、特定标签用户、手动输入号码）。  
- 支持上传文件导入手机号列表，系统自动解析并校验格式。  
- 发送任务将生成独立批次记录，便于后续追踪与管理。  
- 定时发送任务可在指定时间自动触发，适用于预约提醒、活动倒计时等场景。

### 到达率统计分析  
对已发送的短信任务进行多维度数据统计，帮助评估触达效果。  
- 实时展示每批次任务的发送总数、成功数、失败数、到达数。  
- 提供到达率（送达/发送）计算结果，辅助优化发送策略。  
- 支持按时间范围查询整体租户的短信发送表现。  
- 详细记录每条短信的发送状态、运营商返回结果及失败原因。

### 用户退订管理  
管理用户主动取消接收短信的行为，保障合规性与用户体验。  
- 支持手动添加退订号码，记录退订原因与时间。  
- 可查询当前所有退订手机号列表，支持按条件筛选。  
- 在发送短信前可调用接口检查手机号是否已退订，避免无效发送。  
- 退订状态自动同步至发送逻辑，确保不再向该号码推送。

## 常见操作流程

### 创建并提交短信模板审核  
1. 进入短信模板管理页面（若存在前端路由）。  
2. 点击“新建模板”，填写模板名称、编码、内容、签名等信息。  
3. 使用“渲染内容”功能测试变量替换效果，确认无误。  
4. 点击“提交审核”，系统将该模板标记为待审状态，等待管理员审批。

### 批量发送短信  
1. 进入批量发送页面（若存在前端路由）。  
2. 选择短信模板，确认内容无误。  
3. 选择目标类型：可从用户标签、手动输入、文件上传等方式导入手机号。  
4. 点击“立即发送”或“定时发送”，设置发送时间。  
5. 系统生成任务记录，进入任务列表页查看进度。

### 查看发送任务详情与统计  
1. 在任务列表中找到目标任务，点击“查看详情”。  
2. 查看任务基本信息：总数量、已发送数、成功数、失败数。  
3. 点击“到达率统计”获取详细数据，包括送达数、退订数、失败原因分布。  
4. 可导出统计数据用于报表分析。

### 处理退订请求  
1. 进入退订管理页面（若存在前端路由）。  
2. 查看当前退订名单，确认是否存在异常或重复记录。  
3. 若有新增退订需求，点击“添加退订”，填写手机号、用户ID（如有）、退订原因。  
4. 系统自动记录退订时间，后续发送将跳过该号码。

### 取消正在进行的发送任务  
1. 在任务列表中定位到正在执行的批量任务。  
2. 点击“取消任务”按钮。  
3. 系统将停止后续发送，已完成部分保留记录，未发送部分不再处理。

## 相关配置说明  

- **租户级开关**：该模块支持租户独立开启或关闭，由管理员在租户设置中控制。关闭后，所有短信相关功能不可用。  
- **短信模板状态**：模板需经审核通过后才能用于发送，状态包括草稿、待审、已通过、已拒绝。  
- **发送任务类型**：任务分为“立即发送”与“定时发送”，分别对应即时执行与计划执行。  
- **退订机制**：系统自动识别退订号码，防止重复发送；退订记录永久留存，不可删除。  
- **数据存储**：所有短信发送日志、任务记录、到达率数据均按租户隔离存储，确保数据安全与隐私合规。
