# 文件存储使用手册

## 模块简介  
文件存储模块提供租户级的文件上传、下载、预览、分享及配额管理能力。支持按业务实体（如订单、客户、项目）关联文件，实现结构化数据与附件的绑定。通过统一接口管理文件生命周期，保障数据安全与访问控制。该模块解决多租户场景下文件归属不清、存储资源不可控、跨系统共享困难等问题。

---

## 核心功能  

### 1. 文件上传与管理  
支持在租户范围内上传任意类型文件，系统自动记录文件元信息（名称、大小、类型、哈希值等）。上传后可立即获取文件唯一标识，用于后续操作。  
- 支持直接上传至租户根目录。  
- 支持将文件绑定到特定业务实体（如订单、客户、合同），实现“文件归属业务对象”。  
- 可通过接口或控制台完成上传、查看、删除等操作。

### 2. 文件下载与预览  
- **下载**：用户可通过文件 ID 或分享链接下载原始文件内容。  
- **预览**：支持对图片类文件进行在线预览，系统返回缩略图 URL，可在页面中直接展示。  
- 预览与下载均需权限校验，确保仅授权用户可访问。

### 3. 文件分享机制  
- 可为任意文件生成临时访问链接，设置有效期（由系统配置决定，具体时长不固定）。  
- 分享链接无需登录即可访问，适用于外部协作场景。  
- 支持通过分享链接下载文件，无需身份认证。

### 4. 存储用量统计  
- 实时获取当前租户的存储使用情况，包括已用空间、总配额、剩余容量等信息。  
- 管理员可查看所有租户的存储使用汇总，用于资源规划与监控。

### 5. 业务实体文件绑定  
- 支持将文件与特定业务实体（如 `order`, `customer`, `project`）关联。  
- 通过接口可查询某实体下的所有文件，获取其访问地址或下载链接。  
- 适用于表单附件、文档归档、项目资料管理等典型业务场景。

### 6. 租户级存储配置  
- 租户可在控制台配置对象存储服务（如阿里云 OSS、腾讯云 COS 等），选择存储源。  
- 支持动态切换存储介质，系统自动处理磁盘注册与连接状态验证。  
- 配置项包括但不限于：存储服务商、访问密钥、区域、桶名等（敏感信息加密存储）。

## 常见操作流程  

### 流程一：上传文件并绑定至业务实体  
1. 调用 `/api/files/entity/{module}/{entityId}` 接口，传入待上传文件。  
2. 服务器接收文件后，自动将其保存至指定业务实体的文件集合中。  
3. 返回结果包含文件 ID、访问 URL 及元数据信息。  
4. 后续可通过 `getForEntity` 查询该实体的所有文件列表。

### 流程二：生成文件分享链接  
1. 在文件详情页或调用 `/api/files/{id}/share` 接口。  
2. 系统生成一个带签名的临时访问链接。  
3. 将链接发送给外部人员，对方可直接点击下载或预览文件。  
4. 链接过期后失效，无需手动回收。

### 流程三：查看租户存储使用情况  
1. 进入控制台「存储管理」页面（若存在路由）。  
2. 查看当前租户的存储用量图表与详细数据。  
3. 若为管理员，可进入 `/admin/files/usage` 查看所有租户的用量分布。

### 流程四：删除文件  
- 通过 `/api/files/{id}` 发送 DELETE 请求，删除指定文件。  
- 删除操作不可逆，建议确认后再执行。  
- 对于绑定至业务实体的文件，也可通过 `/api/files/entity/{module}/{entityId}` 删除对应文件。

## 相关配置说明  

### 存储配置项  
- **存储源选择**：支持本地磁盘、云端对象存储（OSS）等多种方式。  
- **配置生效状态**：系统会实时判断当前有效存储来源（source），未配置时显示为 `none`。  
- **敏感信息处理**：配置中的密钥、令牌等字段在前端展示时将被脱敏，仅保留部分字符。  
- **更新规则**：修改配置时，若新值为空或掩码，则保留原值；否则更新为新值并重新注册磁盘。

### 权限控制机制  
- 所有文件操作均受 RBAC 权限控制：  
  - 上传文件需具备 `file.upload` 权限。  
  - 删除文件需具备 `file.delete` 权限。  
- 管理员拥有更高权限，可查看全部租户文件、执行全局删除操作。

### 数据模型说明  
文件信息存储于 `FileUpload` 表中，关键字段包括：  
- `tenant_id`：所属租户标识。  
- `user_id`：上传者 ID。  
- `disk`：文件存储位置（如 `oss`, `local`）。  
- `path`：文件在存储系统中的路径。  
- `filename`：原始文件名。  
- `mime_type`：MIME 类型。  
- `size`：文件大小（字节）。  
- `hash`：文件哈希值（用于去重校验）。  
- `category`：文件分类标签（自定义用途标记）。  
- `is_public`：是否公开可见。  
- `metadata`：扩展属性（JSON 格式，可用于业务附加信息）。
