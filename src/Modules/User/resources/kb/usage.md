# 用户管理使用手册

## 模块简介

本模块用于统一管理平台内所有用户的信息与行为，涵盖用户资料、偏好设置、登录日志等核心功能。通过该模块，运营人员可实现对租户及其成员的全生命周期管理，包括创建、编辑、暂停、激活、删除等操作；同时支持跨租户全局搜索用户，便于快速定位和处理异常账户。系统还提供用户登录行为追踪能力，帮助识别潜在安全风险。

本模块主要解决以下问题：
- 多租户环境下用户归属关系混乱；
- 用户信息不统一，难以集中维护；
- 缺乏对用户登录行为的可视化监控；
- 无法高效地进行批量或跨租户用户查询。

## 核心功能

### 租户管理

管理员可在后台对租户进行完整管理，包括创建新租户、查看租户详情、更新租户信息、暂停或激活租户状态。  
- **创建租户**：通过提交必要信息（如名称、联系人等）完成租户注册流程，系统将自动执行开通流程。  
- **修改租户信息**：可调整租户的基本资料，如名称、联系方式等。  
- **暂停/激活租户**：对存在异常或需临时停用的租户执行暂停操作，恢复服务时可重新激活。  
- **删除租户**：移除不再使用的租户，系统将同步清理相关数据。

### 成员管理

在指定租户下，管理员可添加、编辑或移除成员。每个成员属于一个租户，且拥有独立的身份标识。  
- **添加成员**：为租户分配新成员，支持通过邮箱或手机号邀请。  
- **编辑成员信息**：修改成员姓名、联系方式等基本信息。  
- **移除成员**：从租户中移除成员，其账号仍保留但不再隶属于该租户。

### 用户管理

针对特定租户内的用户，提供完整的增删改查能力。  
- **查看用户列表**：以分页形式展示当前租户下的所有用户，支持按姓名或邮箱搜索。  
- **查看用户详情**：获取某用户的详细信息，包括基本信息、偏好设置、登录记录等。  
- **更新用户信息**：修改用户姓名、电话号码、头像等个人资料。  
- **删除用户**：将用户标记为已删除（软删除），不影响历史数据，但用户将无法登录。

### 全局用户搜索

支持跨租户范围的用户检索，适用于需要查找特定用户（如投诉用户、高权限用户）的场景。  
- 可通过用户名或邮箱进行模糊匹配，返回所有符合条件的用户及其所属租户。

### 用户登录日志管理

系统自动记录用户的每一次登录行为，包括时间、IP地址、设备类型等信息。  
- 运营人员可查看单个用户的登录历史，分析登录频率与地点分布。  
- 支持检测异常登录行为，例如异地高频登录、非正常时间段登录等。  
- 可注销指定设备的登录状态，防止未授权访问。

## 常见操作流程

### 创建新租户
1. 进入管理员后台的“租户管理”区域。
2. 点击“新建租户”按钮。
3. 填写租户名称、联系人信息等必填项。
4. 提交表单，系统自动生成租户并启动开通流程。

### 添加租户成员
1. 在目标租户的成员管理页面中点击“添加成员”。
2. 输入成员的邮箱或手机号，系统将发送邀请链接。
3. 成员接受邀请后，自动加入该租户。

### 查找并禁用异常用户
1. 使用“全局用户搜索”功能，输入疑似异常用户的邮箱或姓名。
2. 从结果中定位目标用户，进入其详情页。
3. 查看其登录日志，确认是否存在异常登录行为。
4. 若确认风险，可执行“禁用用户”操作，阻止其继续登录。

### 恢复被误删的租户
1. 在租户管理列表中查找已被删除的租户（若支持回收站机制，请优先检查）。
2. 若租户处于“已暂停”状态，可通过“激活”操作恢复服务。
3. 如需重建租户，需重新创建并重新分配成员。

### 检查用户登录行为
1. 进入目标用户的详情页。
2. 切换至“登录日志”标签页。
3. 查看最近的登录记录，关注登录时间、IP地址、设备信息。
4. 若发现可疑登录，可选择“注销设备”以立即终止该会话。

## 相关配置说明

- **用户偏好设置**：由 `UserPreferenceService` 统一管理，支持个性化配置，如语言、通知方式等。运营人员可通过接口调用或前端界面修改。
- **登录日志保留策略**：系统默认记录用户登录行为，具体存储周期由平台配置决定，不对外暴露细节。
- **短信测试功能**：在租户设置中可触发短信测试，验证短信网关是否正常工作。
- **租户引导注册流程**：支持公开注册入口，允许外部用户通过 `/api/v1/tenants/onboarding/start` 启动注册流程，后续步骤需认证后完成。

> 注：所有操作均受 RBAC 权限控制，仅具备对应权限的角色方可执行相应动作。
