# 投票系统使用手册

## 模块简介  
投票系统用于支持多类型、可配置的在线投票活动，适用于排行榜评选、用户偏好调查、产品推荐等场景。本模块提供完整的投票创建、执行、防刷机制与数据统计能力，帮助运营人员高效管理投票活动。通过租户级开关控制，可灵活启用或关闭该功能。

核心解决的问题包括：  
- 防止恶意刷票行为（基于IP、设备指纹等）；  
- 支持多种投票形式（单选、多选等）；  
- 实时查看投票排名与统计数据；  
- 保障投票结果透明可信。

---

## 核心功能

### 创建与管理投票活动  
运营人员可在系统中创建新的投票活动，设置标题、描述、时间范围、投票规则及展示方式。  
- 支持设定投票开始与结束时间；  
- 可配置每日/总票数限制（按租户或用户维度）；  
- 支持开启防刷机制（如IP限制、设备指纹识别）；  
- 可选择是否公开显示排名与结果。

### 投票执行与防刷机制  
用户在参与投票时，系统将自动校验其投票资格，防止重复或异常操作。  
- 支持单次或多次投票（根据配置）；  
- 系统依据设定规则进行防刷判断（如同一IP或设备指纹在短时间内多次提交）；  
- 投票记录会保存用户ID、IP地址、浏览器信息及设备指纹，便于后续审计。

### 排名与统计查询  
运营人员可随时查看投票活动的实时排名与详细统计数据。  
- **排名查询**：获取当前各选项的得票数排序，支持按票数降序展示；  
- **统计详情**：查看总票数、有效投票人数、各选项得票分布等数据；  
- 数据支持缓存机制，提升查询性能。

### 投票记录追溯  
可查询特定投票活动的所有历史投票记录，包含：  
- 用户ID、投票选项、投票时间、IP地址、设备指纹等信息；  
- 用于分析异常行为或验证投票真实性。

## 常见操作流程

### 1. 创建新投票活动  
1. 进入投票管理界面（若存在前端路由）；  
2. 点击“新建投票”按钮；  
3. 填写投票标题、描述，选择投票类型（如单选、多选）；  
4. 设置投票起止时间，配置每日/总票数上限（按租户或用户）；  
5. 开启防刷功能（如启用IP限制或设备指纹检测）；  
6. 添加投票选项（可上传图片、填写说明），设置排序；  
7. 保存并发布投票。

### 2. 查看投票实时排名  
1. 在投票列表中选择目标投票活动；  
2. 点击“排名”或访问 `/tenants/{tenantId}/voting/{voteId}/ranking` 接口；  
3. 查看各选项当前得票数排名情况。

### 3. 获取投票统计报告  
1. 进入指定投票详情页；  
2. 点击“统计”或调用 `/tenants/{tenantId}/voting/{voteId}/statistics` 接口；  
3. 查看总票数、有效投票人次、各选项占比等汇总数据。

### 4. 审查投票记录  
1. 在投票详情页中点击“记录”或访问 `/tenants/{tenantId}/voting/{voteId}/records` 接口；  
2. 浏览所有已提交的投票记录，包括用户ID、IP地址、设备指纹等字段；  
3. 用于排查异常行为或进行合规审查。

### 5. 更新或删除投票活动  
1. 找到目标投票活动，在管理界面进行编辑；  
2. 修改标题、时间、规则或选项内容；  
3. 保存更改；  
4. 如需终止活动，可执行删除操作（需具备删除权限）。

## 相关配置说明  

- **租户级开关**：该模块支持租户级别启用/禁用，由管理员在租户设置中控制是否可用。  
- **防刷策略**：系统默认启用基础防刷机制，具体行为由 `anti_cheat_ip` 字段控制，可配置为开启或关闭。  
- **数据缓存**：投票统计结果采用缓存机制，避免高频查询对数据库造成压力，可通过服务方法 `clearStatsCache()` 手动清除缓存。  
- **字段说明**：  
  - `status`：表示投票状态（如未开始、进行中、已结束）；  
  - `show_result` / `show_rank`：控制结果与排名是否对外公开；  
  - `metadata`：预留扩展字段，可用于存储自定义配置或标签。  

> 注：所有接口均受权限控制，需具备对应权限方可访问。
